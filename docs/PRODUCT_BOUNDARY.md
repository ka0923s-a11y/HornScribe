# 製品境界（PRODUCT_BOUNDARY）

> Status: 2026-09-24 起票（#190）。「やらないこと」「将来検討」を明文化し、
> 実装判断の基準とする。変更は issue 経由で合意してから更新する。

## 製品の核

HornScribe は**単一音源 → F管ホルン用移調楽譜**のデスクトップツール。
一般の JPOP・歌声・単旋律楽器の録音を、完全無料・オフラインで楽譜化し、
F管ホルンで演奏可能な記譜（+P5 記譜・-P5 移調メタデータ）まで届ける。

## やらないこと（現時点で非目標）

| 領域 | 方針 | 理由 |
|---|---|---|
| 歌詞 | 対象外 | 音声からの歌詞推定は別領域（ASR）。楽譜への歌詞記載も現状行わない |
| 反復記号 | 展開済み記譜のみ | リピート・D.S./コーダの検出は構造解析が必要。まず正確な通し記譜を優先 |
| 総譜・多楽器 | F管ホルン単一パートのみ | voices テクスチャの複数パートは「同じ F 管の声部」として記譜する |
| コードネーム | 未対応 | 単旋律採譜が中核。和音の同時発音記譜は #155 の chords テクスチャで対応（コードネーム表記ではない） |
| バッチ処理 | 1ファイルずつ | レビュー主導のワークフローが前提 |
| クラウド/有料API | 使用しない | 完全無料・オフライン運用が制約（demucs 等のローカルモデルは可） |

## 将来検討（境界の外側だが再評価候補）

- ボーカル分離の前処理（#187）— JPOP ミックスの主旋律精度に直結
- 反復構造の検出 — 同一フレーズの繰り返しをリピート記号に畳む
- 歌詞の手入力添付 — 推定ではなくユーザー入力なら境界内に収まる

## 精度に関する約束

- 推定が不確かな要素（拍子・調・スウィング・声部数）は推測で隠さず、
  ReviewIssue として提示する。ユーザーが確認・修正できることが
  「正しい楽譜」の一部である。
