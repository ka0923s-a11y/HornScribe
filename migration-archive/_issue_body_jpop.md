## 概要

JPOP 風マルチレイヤーミックス（主旋律 + コードパッド + ベース + ドラム系ノイズ、ステレオ）のベンチフィクスチャを新設し、実測で判明した精度問題を修正する。

### 発見した問題（実測）

`texture="melody"` で、ミックス中の主旋律の持続音が Basic Pitch により 8分グリッドで分割検出され、その断片間に低音・パッドの仮説が挟まる。`clean_monophonic` の同音マージは**直前イベントのみ**を見るため、他音が挟まった断片はマージされず、全て別ノートとして残った。

- 修正前: jpop-mix-raw pitch 97.4% / onset F1 0.796 / 余剰 18、jpop-mix-vocal pitch 100% / onset F1 0.779 / 余剰 19
- 余剰は全て主旋律音域（72-81）= 持続音の誤分割

### 修正

`prefer="top"`（melody テクスチャ）で、同ピッチの最後の kept イベントへのマージを追加。ただし **間に挟まったイベントが全て低音のときのみ**（top では低音は伴奏として消えるため橋渡ししても失わない）。高音が挟まった場合は実際の旋律移行としてマージしない。`prefer="onset"`（mono ソロ）は従来挙動を維持。

- 修正後: 両行とも pitch **100%** / onset F1 **1.0** / 余剰・欠落 0

### ベンチの追加

- ステレオ・マルチティンバー合成（lead/pad/bass/noise、等パワーパン）に対応化
- `backing`（真値対象外レイヤー）、`stereo`、`vocal_isolation` フィクスチャ属性、`--only` フィルタを追加
- jpop-mix-raw（分離なし）/ jpop-mix-vocal（vocalIsolation あり）の A/B 行
