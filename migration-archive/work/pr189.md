## Summary

Two engine-selection improvements. Closes #189.

1. **Per-job backend override**: the 採譜オプション popover on the import screen now carries a 採譜エンジン select (auto / Basic Pitch / pYIN) alongside the texture picker — the choice that varies per source no longer requires a round-trip to 設定→詳細設定. 'auto' inherits the global setting; an explicit pin wins for that job only.
2. **Texture-aware auto resolution**: backend=auto now resolves to pYIN when the user declared a mono source (single-line tracker for a single-line source) and Basic Pitch otherwise. meta.backend and ScoreDocument.transcriptionBackend report the resolved engine.

Also fixes a latent inconsistency: a per-job pyin pin would previously have outranked the monophonic-backend issue's 'Basic Pitchで採譜し直す' action; the action now pins the job options too.

## Verification

- New tests: per-job pin beats the global setting; auto inherits; auto+mono resolves meta.backend=pyin without a monophonic warning.
- pytest / ruff / tsc / eslint / vitest green.
