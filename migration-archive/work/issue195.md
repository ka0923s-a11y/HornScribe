## 問題

ENGINE_DEPENDENCY_MISSING（basic_pitch / librosa 等が import 不可）の失敗が、汎用の「採譜に失敗しました + 再試行」面に落ちる。再試行しても環境が変わらない限り必ず再失敗するのに、主アクションが誤誘導になっている。

実際の原因（どのパッケージが足りないか）は診断情報ダイアログの奥に隠れており、ユーザーは復旧方法が分からない。

## 提案

- 失敗イベントの error.code を TranscriptionErrorView に渡し、ENGINE_DEPENDENCY_MISSING 専用のコピーを出す
- 「採譜エンジンの部品（パッケージ名）が見つかりません。アプリを再インストールするか、開発環境なら pip install hornscribe[engine] を実行してください」+ 再試行ではなく診断情報を主アクションに
- details.package をコピー内で表示（エラーコードは出さないが、パッケージ名はユーザーが復旧に必要）

## 受け入れ条件

- 依存欠落時に再試行ボタンが主アクションにならないこと
