## Summary

Fixes the bend-evidence leak: every RawNoteEvent rebuild in clean.py silently dropped pitch_bends, so the vibrato/portamento evidence kept since #169 never reached the quantizer — MIDI bends and audition ramps (#174) were dead code on the real pipeline. Closes #192.

- _extend unions both events' bend series (deduped) when same-pitch detections merge.
- _replace_offset drops bend points past the clipped offset; _replace_pitch keeps them.
