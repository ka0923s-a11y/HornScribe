## 概要
「開く」ダイアログとドラッグ&ドロップが音声ファイルしか受け付けず、保存した `.hornscribe.json` は「最近使ったプロジェクト」一覧経由でしか開けなかった問題を修正します (一覧に載るには一度開く必要がある鶏卵問題)。

## 変更点
- `importRefs`: `.hornscribe.json` を検出したらプロジェクトオープン経路へ (ソース検証 + スコア復元を含む)
- `openProject`: `bytes` 引数を追加 — ブラウザ dev の File 参照も開ける。パス実体のないオープンは recents に記録しない
- `parseProjectFile`: 任意の `displayName` 引数 (File 参照はパスが無いため)
- `runtimePorts`: ダイアログに「HornScribeプロジェクト」フィルタ、file input accept に `.json` を追加
