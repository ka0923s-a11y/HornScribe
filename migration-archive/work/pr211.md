## 変更 (#208)

`quantization_ambiguous` issue が「曖昧です」と伝えるだけで代替解釈を適用する手段がなかった。

### engine

- `generate_review_issues` に `beat_ql` を追加し、issue evidence に代替案（rank-2）の音符スパンを beat 単位で埋め込む（`alternativeNotes`）
- 新 edit kind `applyAlternative`: evidence のスパンで該当 canonical 音符の位置/長さを置き換え、id と evidence を維持。破れたタイフラグはクリア、重なりは拒否、影響小節を再タイル

### desktop

- issue のアクションボタン「別の解釈に切り替え」→ applyAlternative を発行、成功時に issue を fixed
