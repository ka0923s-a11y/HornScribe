## Summary

#169 で確保した pitch bend(ビブラート/ポルタメント)を実際に
ユーザーへ届ける (#174)。

- scorebuild: 各音符のソース bend 曲線を連結し、音符区間で正規化
  (0..1)して canonical QuantizedNote.pitch_bends に保持。
- domain: QuantizedNote.pitch_bends 追加(空ならシリアライズ省略で
  旧ペイロードの revision id を維持)。PitchBendPoint の docstring に
  raw(絶対秒)と canonical(正規化)の意味を明記。
- MIDI export: 正規化曲線を pitchwheel メッセージとして出力、
  音符終端でセンターへ戻す。
- オーディション: bendsByCanonicalId で canonical から曲線を読み、
  両オシレータの周波数を半音オフセットで変調 — ビブラートが
  実際に聴こえる。
