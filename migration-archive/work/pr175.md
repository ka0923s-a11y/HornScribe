## Summary

Adds a second transcription backend, **pYIN** (librosa's probabilistic
YIN tracker), selectable from 設定 → 詳細設定 → 採譜エンジン. Closes #175.

pYIN tracks one continuous f0 contour per frame, which suits the
single-voice sources this app targets (JPOP lead vocals, a played horn
line): vibrato stays inside one note instead of splitting into glued
16ths, and octave flicker is far rarer than with the polyphonic
Basic Pitch model. Basic Pitch remains the default for 'auto' and for
polyphonic material.

## Design

- 'predict_note_events_pyin' runs 'librosa.pyin' (fmin/fmax matched to
  the same detection band as Basic Pitch, widened to 1400 Hz for
  melody-texture jobs) and converts its frame output through the pure
  'frames_to_note_events' helper into the same note-tuple shape the
  existing pipeline consumes — so cleaning, quantization, key
  estimation, and review issues behave identically.
- Runs of voiced frames sharing a rounded pitch become one note; runs
  split by a single unvoiced frame (tracker dropout) are merged; runs
  under 70 ms are dropped, matching the Basic Pitch minimum.
- Per-frame f0 deviation is kept as pitch-bend evidence measured from
  the quantized note pitch (same convention as Basic Pitch), so
  performed vibrato/scoops survive into MIDI export and audition.
- Unvoiced gap frames (NaN f0) inside merged runs borrow the nearest
  voiced neighbour for the bend series; NaN voiced-probabilities are
  excluded from the confidence average.
- Provenance: 'RawNoteEvent.source' reports 'pyin', 'meta.backend'
  resolves to 'pyin'/'basic_pitch', and 'meta.backendVersion' reports
  the installed librosa version for pyin jobs.

## UI

- 設定 → 詳細設定 → 採譜エンジン gains a 'pYIN（単音）' option with a
  hint explaining it suits a single sung/played line.
- 'BackendSetting' / settings validation accept 'pyin'; the value is
  forwarded through 'transcriptionParams' to the worker.

## Caveats

- pYIN is strictly monophonic: on polyphonic sources it tracks the
  dominant line and the result is one voice. The option is labelled
  accordingly.
- Like 'predict', 'pyin' is a single blocking call — cooperative
  cancellation relies on the worker's terminate/restart fallback.

## Verification

- 'pytest tests/python' — all green (new 'TestFramesToNoteEvents'
  covers run grouping, vibrato grouping, pitch-change splits,
  single-frame dropout merge with NaN f0, short-run drop, bend
  deviation from the quantized pitch, NaN probability handling).
- 'ruff' / 'mypy' clean; 'tsc --noEmit', 'eslint', 'vitest' green on
  the touched desktop files.
- librosa is an engine extra not installed in the dev venv, so the
  pyin path itself is exercised through the pure converter; the
  end-to-end smoke needs an '[engine]' install.
