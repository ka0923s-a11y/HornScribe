## Summary

Fixes #160, fixes #161.

### playback.mid fidelity (#160)

The desktop MusicXML -> SMF builder read only the first sound tempo and
the first time signature. A tracked-tempo transcription (rit./accel.
preserved as per-boundary TempoSegments) played back at the head tempo,
and mid-piece meter changes never reached the SMF. The measure walk now
collects (tick, bpm) marks from direction/sound elements and
(tick, n/d) marks from attributes<time>, deduped across parts (every
part repeats the same marks), and emits one meta event per mark at its
tick. The open tie map also moved inside the part loop — a shared map
could merge a tied note in voice 1 with a same-pitch note in voice 2
now that multi-voice scores ship (#148).

### Export dialog (#161)

The submit button gated on anyChecked while the export filtered blocked
formats, so a selection of only blocked formats (e.g. PDFs with no
MuseScore) produced a zero-file "done". The effective format list is
now computed once and shared between the disabled state and submit.

## Tests

  reader), and the two-part tie fixture keeps both notes.
