## Summary

休符を音符に変換する編集を追加 (#163)。スコアビューで休符をクリックして
コマンドパレット/メニューから「休符を音符に変換」を実行すると、その休符
アトムの位置に新しい音符が挿入される。ピッチは直前の音符を引き継ぎ、
音価はクリックしたアトムの長さがデフォルト。残りは休符として再配置され、
小節構造・テンポマップ・他の音符は変わらない。

## Engine

- New restToNote score-edit kind (partId, startBeat, pitchMidi,
  optional durationBeats). The start beat must land inside a rest span;
  the new note defaults to the remainder of the span and leftovers
  re-tile as rests through the shared _retile_part path.
- The new note gets a fresh sn-* id and empty source_event_ids
  (no backend evidence yet).

## Desktop

- restSpans.ts: maps a clicked hs-rest-<ordinal> back to the canonical
  rest atom (partId, atom start, atom duration). The export numbers one
  element per rest atom in document order, so walking the payload's
  atoms recovers the ordinal's target.
- score.restToNote command, gated on a rest-glyph selection
  (hasRestSelection). After the edit the fresh note is selected so
  pitch/duration tweaks are one keystroke away.
