## 変更

- workflow_dispatch の tag 入力を `RELEASE_TAG` env で正規化
  (`0.1.0` → `v0.1.0`、`v0.1.0` → そのまま)。push トリガーは
  `github.ref_name` をそのまま使う。
- checkout 前に `gh api .../git/ref/tags/<tag>` でタグの存在を検証し、
  無い場合は分かりやすいエラーで即失敗。
- checkout / バージョン照合 / zip 名 / release publish がすべて
  正規化済みタグを参照するように統一。

run 35993338213 / 35993543130 は `0.1.0` (v 無し) 入力で checkout の
