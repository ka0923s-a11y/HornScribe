## 単音ソース向けに librosa pyin バックエンドを追加して JPOP ボーカル精度を上げる

### 背景
現在の唯一のバックエンドは Basic Pitch(ポリフォニック汎用モデル)。
単音メロディ(ホルン独奏・JPOP ボーカル)に対しては、専用の単音
ピッチトラッカー librosa pyin の方が一般に精度が高い:

- フレーム単位の連続ピッチ推定で、ビブラートを「1 音の揺れ」として
  自然に捉える(Basic Pitch のノート分割フリッカーが起きにくい)
- オクターブ誤りが少ない
- 既に librosa はエンジン依存に含まれている(追加コストゼロ、
  完全無料運用を維持)

### 期待
- backend 選択に pyin(単音) を追加(auto / basicPitch / pyin)。
  単音ソースでは pyin を既定または推奨にできる。
- pyin のフレームピッチ列を RawNoteEvent へ変換(有声フレームを
  連結してノート化、セント単位の細かいピッチを pitch_bends として
  保持できれば #169 の枠組みと整合)。
- 設定のバックエンド選択 UI に pyin を露出。

### 精度との関係
「一般 JPOP を完全に正しく楽譜化」の核。ボーカルメロディの
ノート境界・オクターブ・ビブラートの扱いが Basic Pitch より
安定する可能性が高い。

### 検証
同一 JPOP ボーカルソースで basicPitch vs pyin の出力を比較し、
ノート数・オクターブ誤り・手修正量で評価するベンチを用意する。
