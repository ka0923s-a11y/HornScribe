## Summary

Part of #134 — swing/shuffle feel is now detected and reported as a review issue instead of being silently written as triplets.

- **transcription/swing.py**: censuses normalized offbeat onsets by beat phase — triplet (~1/3), straight (~1/2), swing (~2/3). A piece reads as swung when the 2/3 cluster dominates (>=55% of offbeats, more than the straight cluster) while the 1/3 cluster stays quiet (<=25%), which separates a shuffle from genuine triplet writing. Beat-length aware (compound meters OK); needs >=12 offbeats before it says anything.
- **Pipeline**: emits a whole-piece swing_feel review issue (CAUTION) with the census in evidence.
- **Desktop**: swing_feel added to the reason enums + copy decks (ja.ts, protocol/copy/ja-JP.json); the inspector detail shows the offbeat census (裏拍の音 N 個中 M 個が三連符の3つ目の位置に寄っています).

Not in this PR: swing *notation* (MusicXML direction/sound swing) — #134 documents that as the follow-up, and the review issue already tells the user to compare against the source audio.
