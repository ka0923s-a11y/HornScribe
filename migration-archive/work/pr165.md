## Summary

調に沿った音名スペリングを実装 (#165)。これまで music21 の
Pitch(midi=) デフォルト綴りに任せていたため、フラット系の調でも
調外音がすべてシャープ表記になっていた。notation/tone_spelling.py
で、五度圏上でその調の音階ブロックに最も近い異名同音を選ぶ
(フラット系の調はフラット寄り、シャープ系はシャープ寄り、
ダブルシャープ/ダブルフラットは出さない)。書き込み F 管ビューは
書き込み調号(実音+1 fifth)に対して綴る。

あわせて、長らく定義だけ存在した pitch_spelling_ambiguous レビュー
issue を実際に発行するようにした (#166)。調が決められない調外音の
ピッチクラスごとに 1 件・上限付き・INFO で出し、黙って推測しない
という clean.py の契約を実現する。手動の異名同音トグル(E キー)は
従来通り使える。

## Examples

- Eb 長調の MIDI 66 → F#4 ではなく G-4 (Gb)
- C 長調の MIDI 66 → F#4 (従来通り)
- B 長調の MIDI 72 → B#4 (導音、C5 ではない)
