#25 UI-020: Japanese empty state, audio-ready state, and import UX

## Goal

Implement the first-run/import experience with clear Japanese guidance and minimal cognitive load.

## Depends on

- UI-011
- UI-012
- UI-004 for real waveform integration when ready

## States

- EMPTY
- OPENING_AUDIO
- AUDIO_READY
- AUDIO_ERROR
- SOURCE_MISSING

## Required UI

Empty:

- drop target
- 「音声ファイルを開く」
- supported formats
- local-processing trust message
- recent projects when available

Audio ready:

- waveform
- transport
- primary 「採譜を開始」
- advanced transcription settings hidden by default

## Acceptance criteria

- [ ] first-time user can identify primary action immediately
- [ ] drag/drop and Ctrl+O both work
- [ ] invalid file has actionable Japanese error
- [ ] unsupported codec does not dead-end
- [ ] source file is never modified
- [ ] recent project path failure provides relink action
- [ ] no backend/FFmpeg/quantizer internals are visible in normal state
- [ ] visual fixtures cover empty/audio-ready/error
