#17 QNT-003: Joint note-duration/rest realization and notation complexity cost

## Goal

Implement the core HornScribe-specific improvement: choose note duration and following rest jointly with onset transitions, balancing offset evidence and readable notation.

## Depends on

- QNT-002

## Scope

Implement:

- `realize_interval(start, next_onset, observed_offset, meter_tree)`
- candidate note-end generation
- note span decomposition
- rest span decomposition
- notation atom cost
- tie cost
- first/second dot cost
- tiny-rest penalty
- strong/weak metrical-boundary crossing cost
- memoized span realization
- monophonic overlap handling
- repeated-same-pitch preservation

## Horn-specific behavior

Raw AMT offset is soft evidence.

Small gaps from tonguing/staccato/breath must not automatically become tiny rests.

Repeated same-pitch events remain distinct if they enter the quantizer as distinct event IDs.

## Acceptance criteria

- [ ] genuine quarter-rest fixture produces a rest
- [ ] small articulation-gap fixture does not produce unnecessary 16th rests
- [ ] repeated tongued same-pitch fixture remains multiple notes
- [ ] overlapping raw offsets are clipped/handled without invalid score durations
- [ ] note crossing a barline can be decomposed with a tie
- [ ] weak-start span that hides a strong beat can be represented more readably via tie when cost prefers it
- [ ] notation decomposition is deterministic
- [ ] all measure duration invariants hold
- [ ] span realization is memoized/profiled
- [ ] timing-only ablation remains available for comparison

## Non-goals

- automatic articulations
- slurs
- swing
- complex tuplets
