#18 QNT-004: Meter expansion, compound meter, and pickup phase

## Goal

Make HSQ-v1 meter-aware beyond 4/4 and validate notation behavior in simple and compound meters.

## Depends on

- QNT-003

## Scope

Complete/test:

- 3/4
- 2/4
- 6/8
- measure boundary handling
- meter-aware rest grouping
- manual `measure_phase_ql`
- manual pickup/anacrusis
- ReviewIssue for ambiguous/invalid phase supplied by upstream estimation

## Required behavior

6/8:

- measure length = 3 ql
- primary groups = 1.5 + 1.5 ql
- eighth-note thirds inside each compound beat are native, not triplets

## Acceptance criteria

- [ ] 3/4 measures close exactly
- [ ] 2/4 measures close exactly
- [ ] 6/8 native eighth pattern gets no tuplet notation
- [ ] compound-meter dotted values receive appropriate low complexity
- [ ] pickup fixture creates a partial first measure correctly
- [ ] changing pickup/meter can re-quantize without re-running AMT
- [ ] meter-specific golden fixtures round-trip through MusicXML
- [ ] invalid phase fails safely

## Non-goals

- automatic time-signature inference
- odd meters
- automatic pickup inference
