#12 FND-002: Python runtime and Basic Pitch packaging compatibility matrix

## Goal

Select the Python engine runtime from measured evidence rather than fixing Python 3.10 by assumption.

## Context

- Python 3.10 reaches EOL in October 2026.
- Basic Pitch 0.4.0 currently declares support through Python 3.11.
- Basic Pitch Python 3.12 work is active upstream.
- The dependency path differs by Python/platform and affects bundle size and startup cost.

## Candidates

Measure at least:

1. Python 3.10 + current Windows Basic Pitch/ONNX path
2. Python 3.11 + official Basic Pitch dependency path
3. Python 3.12+ only if a stable, reproducible Basic Pitch-compatible path exists at test time

Python 3.10 may be used as a compatibility reference but must not be selected as the long-term baseline without an explicit migration date.

## Measurements

For each viable candidate record:

- install success
- dependency lock
- Basic Pitch smoke inference
- 30 sec inference runtime
- cold import/start time
- model initialization time
- peak RAM
- packaged sidecar size
- PyInstaller/Nuitka or selected freeze method success
- offline packaged execution
- cancellation behavior
- known upstream limitations

## Deliverable

Commit `docs/ENGINE_RUNTIME_MATRIX.md` with results and recommendation.

## Acceptance criteria

- [ ] results are reproducible from documented commands
- [ ] version/lock files are captured
- [ ] no hidden runtime model download is required
- [ ] candidate can be frozen into a sidecar or an explicit blocker is recorded
- [ ] chosen runtime has lifecycle risk documented
- [ ] migration trigger is documented
- [ ] ADR/Development Plan is updated after decision
