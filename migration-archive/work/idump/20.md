#20 QNT-006: QuantizedRhythmRevision to music21/MusicXML realization

## Goal

Turn HSQ-v1's canonical rhythm decisions into stable notation without letting the notation library silently change the quantizer result.

## Depends on

- QNT-005
- ENG-001

## Scope

Implement:

- `QuantizedRhythmRevision -> ScoreDocument`
- music21 duration objects
- measures
- rests
- ties
- tuplets
- beaming
- MusicXML export
- canonical note ID preservation
- Verovio/MuseScore integration fixtures

## Architecture rule

HSQ decides musical onset/duration/rest/tie intent.

music21 realizes/serializes notation.

Do not call music21 quantization as a hidden second quantizer.

## Acceptance criteria

- [ ] exported MusicXML preserves HSQ onset/duration exactly
- [ ] canonical note IDs map to MusicXML note IDs
- [ ] rests/ties/tuplets survive reload
- [ ] barline ties are correct
- [ ] 6/8 grouping renders correctly
- [ ] Verovio renders representative fixtures
- [ ] MuseScore opens representative fixtures
- [ ] reload comparison detects any rhythm mutation
- [ ] Concert/Horn projection does not alter rhythmic identity
- [ ] no UI dependency

## Non-goals

- engraving-perfect manual beaming controls
- articulation inference
