#15 QNT-001: TimeWarp, BeatMap, MeterMap, and MetricalTree contracts

## Goal

Implement the deterministic timing/meter contracts required by HSQ-v1 before any quantization search logic.

## Depends on

- FND-001

## Scope

Implement:

- `BeatAnchor`
- `MeterSegment`
- `TimeWarp`
- `MetricalTree`
- `QuantizationProfile`
- `QuantizationDiagnostics`
- exact `Fraction` score positions after quantization boundaries

## TimeWarp

Support:

1. fixed-BPM mode
2. piecewise-linear BeatMap mode

Beat anchors map:

```text
seconds -> score_pos_ql
```

Interpolation must be monotonic and pass exactly through all anchors.

## MeterTree

Required meters:

- 4/4
- 3/4
- 2/4
- 6/8

6/8 must represent two compound beats of 1.5 quarterLength each; native ternary subdivision must not be classified as a tuplet.

## Acceptance criteria

- [ ] fixed 120 BPM maps 0.5 s -> 1.0 ql
- [ ] piecewise-linear TimeWarp passes exactly through anchors
- [ ] inverse mapping ql -> seconds exists for deterministic fixtures
- [ ] invalid/non-monotonic BeatMap fails clearly
- [ ] 4/4 meter tree has correct measure/beat/subdivision positions
- [ ] 6/8 compound structure is represented correctly
- [ ] meter positions use exact Fraction where symbolic
- [ ] no audio/GUI dependency
- [ ] unit tests cover extrapolation and tempo change
- [ ] API/docs match docs/QUANTIZER_DESIGN.md

## Non-goals

- beat tracking
- automatic meter detection
- DP quantization
- triplets in simple meters
