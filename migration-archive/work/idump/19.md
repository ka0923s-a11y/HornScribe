#19 QNT-005: Triplet model, grid-mode consistency, and quantization ambiguity

## Goal

Add controlled 8th-note triplet support without converting ordinary expressive timing into unnecessary tuplets.

## Depends on

- QNT-004

## Scope

Implement:

- 8th-triplet candidate grid in simple meters
- triplet region evidence gate
- binary vs triplet local model comparison
- grid-mode state
- mode-switch penalty
- tuplet group/atom notation cost
- k-best ambiguity detection
- ReviewIssue generation

## Review reasons

- `possible_triplet`
- `quantization_ambiguous`

Japanese UI copy is defined in docs/JAPANESE_UI_COPY.md.

## Required fixtures

- exact 8th triplet
- triplet with timing jitter
- straight 8ths with jitter
- isolated late note that must not flip a region to triplet
- binary -> triplet -> binary passage

## Acceptance criteria

- [ ] exact triplets are recovered
- [ ] straight jitter fixture stays binary
- [ ] 6/8 native ternary is still not treated as a tuplet
- [ ] triplet candidate requires configured/evidence gate
- [ ] mode-switch penalty prevents one-note grid flicker
- [ ] top-1/top-2 close alternatives generate ReviewIssue only when resulting notation differs
- [ ] ambiguous range points to canonical note IDs/time range
- [ ] triplet behavior is deterministic

## Non-goals

- 16th-note triplets
- quintuplets/septuplets
- nested tuplets
- swing notation
