#1 UI-001: Tauri 2 + React desktop shell spike

## Goal

Validate the proposed Tauri 2 + React desktop shell before committing HornScribe to the new GUI architecture.

## Scope

- Tauri 2 / Rust
- React + TypeScript + Vite
- Fluent UI React v9 installed as component/accessibility foundation
- HornScribe semantic design tokens
- light / dark / follow-system themes
- restrictive Tauri capability/CSP baseline

No transcription features yet.

## Deliverables

- `apps/desktop/`
- build/dev commands
- Tauri capability files
- CSP configuration
- minimal app shell
- packaging notes
- measured cold startup and baseline memory

## Acceptance criteria

- [ ] starts on Windows 11
- [ ] development and packaged build both work
- [ ] 1366×768 is usable without application-level horizontal scrolling
- [ ] 100%, 150%, and 200% Windows scaling pass smoke test
- [ ] light/dark/system themes work
- [ ] visible keyboard focus exists
- [ ] every user-visible label in the shell is Japanese
- [ ] accessible names in the shell are Japanese
- [ ] no runtime CDN/network dependency
- [ ] CSP is enabled and documented
- [ ] frontend does not receive broad filesystem permission
- [ ] application shell becomes interactive without loading Python/ML
- [ ] cold-start and baseline memory measurements are recorded
- [ ] exact setup/build commands are documented

## Non-goals

- waveform
- score rendering
- Basic Pitch
- final styling
- English UI / language switcher
- production installer
