#27 UI-040: Transcription job, cancellation, progress, and failure UX

## Goal

Make long-running transcription understandable, honest, and recoverable.

## Depends on

- UI-002
- UI-011
- baseline engine job protocol

## Stages

Map internal stages to Japanese user copy:

- 音声を準備しています
- 音を解析しています
- 検出結果を整理しています
- リズムを解析しています
- 音符の長さと位置を整えています
- 楽譜を作成しています
- 楽譜を表示しています

## Rules

- no fake progress %
- no unstable ETA
- UI remains usable where safe
- cancel status is explicit
- partial/raw data is never silently presented as finished score
- retry is explicit
- worker crash preserves valid project state

## Acceptance criteria

- [ ] determinate/indeterminate states are distinct
- [ ] cancellation ends in a deterministic terminal state
- [ ] cancel/retry copy is Japanese
- [ ] worker crash has recovery action
- [ ] no modal spinner blocks the entire application
- [ ] partial failure does not destroy prior valid score
- [ ] screen-reader progress semantics are present
