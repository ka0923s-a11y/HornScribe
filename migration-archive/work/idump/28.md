#28 UI-050: Review workspace for uncertain transcription results

## Goal

Make HornScribe's differentiating workflow—checking only suspicious passages—fast enough for repeated real use.

## Depends on

- UI-030
- ReviewIssue backend contract
- QNT ambiguity reasons where applicable

## Header

- 要確認 n / total
- 前へ
- 元音源を再生
- 問題なし
- 次へ

## Required review reasons

At minimum support product-level reasons from docs/JAPANESE_UI_COPY.md.

## Required interactions

- jump to issue
- loop source range
- select associated canonical note(s)
- mark resolved/dismissed
- pitch correction
- delete/restore
- undo/redo
- move next/previous without menus

## Visual rule

Review state must not rely on red/green or raw confidence alone.

## Acceptance criteria

- [ ] 20 review items can be processed without opening menus
- [ ] core review flow works keyboard-only
- [ ] source audio can be replayed immediately
- [ ] resolved state persists
- [ ] undo restores previous correction/review decision
- [ ] raw model confidence, if shown, is labeled as evidence rather than probability of correctness
- [ ] no color-only encoding
