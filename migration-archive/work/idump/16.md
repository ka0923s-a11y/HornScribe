#16 QNT-002: Fixed-BPM baselines, candidate lattice, and k-best onset DP

## Goal

Implement the first HSQ-v1 onset quantizer and prove that global dynamic programming improves over independent nearest-grid rounding.

## Depends on

- QNT-001

## Scope

Implement:

### Baselines

- B0 nearest 16th
- B1 nearest binary candidate grid
- optional wrapper for music21 Stream.quantize benchmark

### HSQ onset search

- normalized note input
- binary candidate generation
- candidate window
- Huber onset cost
- inter-onset-interval cost
- monotonic transition rules
- deterministic top-K dynamic programming
- K=3 default
- global AMT/beat alignment shift search

Do not implement final duration/rest realization yet.

## Required fixtures

- quarter notes with jitter
- eighths
- sixteenths
- syncopated onset sequence
- global +40 ms latency
- tempo change with explicit BeatMap

## Acceptance criteria

- [ ] exact straight rhythms quantize correctly
- [ ] ±20/50 ms jitter fixtures recover intended onset grid at configured BPM
- [ ] global latency fixture estimates/handles shift deterministically
- [ ] DP result is deterministic
- [ ] top-3 alternatives can be returned
- [ ] tie-break ordering is documented
- [ ] no candidate produces non-monotonic note order
- [ ] IOI cost can be disabled for ablation
- [ ] B0/B1/HSQ onset metrics are emitted by benchmark helper
- [ ] no note duration is permanently mutated at this phase

## Non-goals

- rests
- ties
- triplets
- grace notes
- final MusicXML
