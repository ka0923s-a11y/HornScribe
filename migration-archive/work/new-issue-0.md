## 背景\n\n#70 で録音は ppDataDir/recordings/ に実ファイルとして永続化されるようになったが、現在は**書きっぱなし**で以下が未定義:\n\n- 容量上限・古い録音の自動削除ポリシーが無い(30分録音は ~660MB)\n- 録音ファイルの一覧・削除・名前変更の UI が無い\n- プロジェクト保存時に録音ファイルをプロジェクト側にコピー/同梱するか、appDataDir 参照のままにするか未決定 — 現状は後者で、アプリ削除や別PC移行でリンク切れになる\n- アンインストール時に recordings/ が残る\n\n## 提案\n\n- 設定画面に「録音の保存場所」「自動削除(日数/容量)」を追加\n- 録音一覧の管理画面(再生・削除・プロジェクトへの紐付け表示)\n- プロジェクト保存時に録音をプロジェクトディレクトリへコピーするオプション\n\n## 関連\n\n- #60 FEAT-001(本体), #70(永続化), PR #61
