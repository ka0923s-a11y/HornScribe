## 概要

ユーザー実機報告: 「インストール、ポータブル版両方」で起動時に `WebView2Loader.dll が見つからないため、コードの実行を続行できません` (hornscribe-desktop.exe - システムエラー) が出る。

#141/#142 で v0.2.1 に修正済みのはずだが、報告が継続したため公開アセットを実機検証した。

## 検証結果 (v0.2.1 公開アセット)

| アセット | 検証 | 結果 |
|---|---|---|
| portable zip | zip 内に HornScribe/WebView2Loader.dll (160,320 B) が exe 隣に同梱 | OK |
| 同上・実展開して HornScribe.exe 起動 | プロセス生存 + ウィンドウ表示 + msedgewebview2 子プロセス起動 | OK |
| setup.exe | NSIS ペイロードに WebView2Loader.dll (160,320 B) が hornscribe-desktop.exe と同階層で同梱 | OK |
| 同上・ペイロード抽出して起動 | エラーなしで起動 | OK |

v0.2.1 アセット自体は両方とも正常。ユーザーが踏んだのは v0.2.0 アセット (起動不能なまま公開中) か、zip 内で exe だけを直接実行/取り出した形と推定される。

## 問題

- v0.2.0 の setup/portable バイナリは「絶対に起動できない」壊れたアセットのままダウンロード可能。リリースノートへの警告追記だけでは、一覧から辿ったユーザーが確実に踏む。
- ポータブル版は zip 内で exe 単体をダブルクリックすると、Windows が exe のみを一時展開して DLL 不在で同一エラーになる (README は zip の中なので展開前に読めない)。

## 対応

1. v0.2.0 の破損バイナリアセットを削除 (リリースエントリ自体は記録として残し、ノートで v0.2.1+ を案内)
2. エラー自体は OS ローダーがプロセス起動前に出すためアプリ側では抑制不可能。予防策は「壊れたアセットを残さない」ことのみ。

## 対象

v0.2.0 の setup.exe / portable.zip を gh release delete-asset で除去。
